Exercício 4
Enunciado

O exercício pede:

Caso Base
fluxo_energia(A,D) :-
    come(A,D).
Passo Recursivo
fluxo_energia(A,D) :-
    come(A,Z),
    fluxo_energia(Z,D).
Problema no seu código

Você escreveu:

fluxo_energia(sol, A) :-
    come(A, sol).

e

fluxo_energia(A, D) :-
    come(A, D),
    D \= sol.

Isso altera a lógica original do exercício.

Além disso, no seu banco:

come(girassol, sol).

significa:

girassol se alimenta do sol.

Logo, o fluxo deveria ser inferido a partir dessa relação.

Versão mais próxima do enunciado
fluxo_energia(A, D) :-
    come(A, D).

fluxo_energia(A, D) :-
    come(A, Z),
    fluxo_energia(Z, D).
Porém...

No seu banco de dados não existe cadeia alimentar completa.

Você tem:

come(girassol, sol).
come(cacto, sol).
come(suculenta, sol).

mas ninguém se alimenta de:

girassol
cacto
suculenta

Então a recursão praticamente não será utilizada.

Para responder à query do exercício

O exercício pergunta:

Para quem o Sol envia energia (direta ou indiretamente)?

Uma forma simples seria:

recebe_energia(X) :-
    fluxo_energia(X, sol).

Consulta:

?- recebe_energia(X).

Resultado:

X = girassol ;
X = cacto ;
X = suculenta.
